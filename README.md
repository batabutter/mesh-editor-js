# Vanilla JS Graphics Demo

### This is a small mesh editor that showcases camera rotation, and mouse events in a 3D geometric space rendered in Vanilla JS

### **How to run:**
- Simply Copy-Paste the HTML into your browser and have a blast

## **Other notes**
- This demo is meant to serve as a reference for my larger "3D Mesh-Editor" Project that I plan to refine using OpenGL and C++. For now, this is the demonstration of what I hope to build upon.
